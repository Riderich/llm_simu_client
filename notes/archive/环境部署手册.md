## 二、GPU 使用规范

### 2.1 可用 GPU
- **GPU 4**：主要工作 GPU（48GB A6000）
- 其他 GPU：视情况使用

### 2.2 显存管理

**Transformers 方案（推荐）**：
```python
import os
os.environ["CUDA_VISIBLE_DEVICES"] = "4"

import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

device = torch.device("cuda:0")  # 注意：CUDA_VISIBLE_DEVICES=4 后，cuda:0 实际对应物理 GPU 4
torch.cuda.set_device(0)

model = AutoModelForCausalLM.from_pretrained(
    model_path,
    torch_dtype=torch.bfloat16,
    trust_remote_code=True,
).to(device)
```

**vLLM 方案（慎用）**：
- vLLM 0.6.3 的 `multiproc_gpu_executor` 会忽略 `CUDA_VISIBLE_DEVICES`
- 如需使用，确保 GPU 0 空闲或 kill 相关进程

### 2.3 避免 OOM
- 使用 `torch_dtype=torch.bfloat16` 节省显存
- 批量大小控制在 8 以内
- 使用 `device_map="auto"` 时确保理解其实际映射

## 三、后台任务管理

### 3.1 启动任务

**正确方式**：
```bash
cd /data5/zxj/llm_simu_client/workspace

nohup /data5/zxj/miniconda3/envs/recap_vllm/bin/python -u \
  scripts/your_script.py \
  --arg1 value1 \
  > /tmp/your_script.log 2>&1 &
```

**关键参数**：
- `-u`：unbuffered output，实时写入日志
- `nohup`：用户退出后任务继续运行
- 直接使用 Python 二进制路径（不要用 `conda run`）

### 3.2 查看任务状态

```bash
# 查看进程是否存在
ps aux | grep your_script.py | grep -v grep

# 实时查看日志
tail -f /tmp/your_script.log

# 查看日志末尾（快速检查是否完成）
tail -100 /tmp/your_script.log
```

### 3.3 停止任务

```bash
# 查找 PID
ps aux | grep your_script.py | grep -v grep

# 停止任务
kill <PID>

# 强制停止
kill -9 <PID>
```

## 五、问题排查

### 5.1 权限问题

**症状**：脚本无法写文件
**临时修复**：
```bash
chmod -R u+w /data5/zxj/llm_simu_client/workspace
```

**根本原因**：多次 `conda run` / 手动操作导致所有者不一致

### 5.2 模型加载失败

**症状**：`CUDA error: invalid device ordinal`
**解决**：确保 `CUDA_VISIBLE_DEVICES` 设置正确，使用 `cuda:0` 而非 `cuda:4`

### 5.3 API 限流

**症状**：Qwen API 返回 rate limit 错误
**解决**：
- 减少并发数（降低 `--workers`）
- 增加重试间隔（指数退避）
- 更换模型（`qwen3.5-flash` → `qwen3.5-plus`）

### 5.4 显存不足

**症状**：`torch.OutOfMemoryError`
**解决**：
- 减小批量大小
- 使用 `torch_dtype=torch.bfloat16`
- 清空 GPU 缓存：`torch.cuda.empty_cache()`
