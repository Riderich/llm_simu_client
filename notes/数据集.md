## 各数据集说明

### ESConv — 主力数据集（众包模拟危机咨询）

- 来源：情感支持对话，众包双人模拟，Helping Skills Theory 策略标注
- 规模：1,300 对话 / 31,410 utterances（平均 29.8 轮）
- **标注特征**：阻抗率高（29.0%），以 A2-争辩贬低为主（76.2%）——反映模拟场景的情绪化特点
- 本地路径：`workspace/dataset/ESConv.json`
- 标注输出：`workspace/results/esconv_resistance.json`（阻抗）/ `workspace/results/esconv_coop.json`（合作）
- Profile 输出：`workspace/results/profiles/esconv_profiles_full.json`

### MESC — 高质量补充（真实心理治疗录像）

- 来源：TV 剧《In Treatment》第 1-3 季，真人治疗师-患者互动，多模态标注
- 规模：1,019 对话 / 28,762 utterances（平均 28.2 轮）
- **标注特征**：阻抗率低（8.7%），以 A1-争辩挑战（61.1%）和 C1-最小回应（22.1%）为主——真实咨询更理性克制
- 本地路径：`workspace/dataset/MESC_merged.json`
- 标注输出：`workspace/results/mesc_resistance.json` / `workspace/results/mesc_coop.json`
- Profile 输出：`workspace/results/profiles/mesc_profiles_full.json`

### AnnoMI — 专家标注金标准（MI 专项）

- 来源：YouTube 真实心理咨询视频转写，专家标注，含高/低质量 MI 演示
- 规模：133 transcripts / 9,699 utterances（平均 72.9 轮，对话最长）
- 原始标注：`client_talk_type`（sustain/change/neutral）+ RECAP 二分类
- **当前状态**：细粒度标注后台运行中（`nohup`）
  - 阻抗 1,290 条 → A1-D2（GPU 4，RECAP 本地模型）
  - 合作 5,418 条 → CBS2-8（Qwen API）
- 本地路径：`data/processed/AnnoMI-full.json`
- 标注输出（进行中）：`workspace/results/annomi_resistance.json` / `workspace/results/annomi_coop.json`
- 日志：`workspace/results/profiles/logs/annomi_resistance_nohup.log`

### RECAP (ClientResistance) — 中文阻抗金标准

- 来源：西湖大学李安琪团队，真实中文心理咨询，utterance 级别 14 类标注
- 规模：5,154 条标注样本（4,154 阻抗 / 1,000 合作）
- 标签体系与我们的行为空间框架直接对齐
- 本地路径：`data/raw/ClientResistance_decrypted.json`
- 预处理输出：`workspace/results/annomi_full_binary_recap.json`（二分类）

### ExTES — 辅助语料（no-resistance 补充）

- 来源：基于 ChatGPT in-context learning 生成的合成数据，场景覆盖广
- 阻抗比例仅 6%，质量偏弱（多为短暂悲观情绪，随即软化配合）
- **定级**：不作主力，可作 no-resistance 补充语料防止训练偏差
- 本地路径：`workspace/dataset/ExTES.json`

## 标注流程说明

```
client utterance
  → RECAP 本地模型（GPU 4）→ 二分类：阻抗 / 合作
  → 阻抗：RECAP 模型 → A1-D2（11类阻抗）
  → 合作：Qwen API → CBS2-8（7类合作）
```

- 阻抗分类脚本：`workspace/scripts/annomi_resistance_fine.py`（AnnoMI）/ `mesc_resistance_fine.py`（MESC）
- 合作分类脚本：`workspace/scripts/annomi_coop_cbs.py`（AnnoMI）/ `esconv_coop_cbs.py`（ESConv）
- Profile 提取：`workspace/scripts/run_profile_extraction.py`（支持 `--data-format annomi/esconv/mesc/recap`）
