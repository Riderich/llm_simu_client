# 数据集总览

> **更新日期**：2026-04-18  
> **用途**：阻抗 / 合作标注、对话视图、Profile、CoT 与 SFT 的数据规模与文件索引。  
> **产出目录与文件命名**：见 `workspace/results/README.md`（含旧文件名对照表）。  
> **统计口径**：下表「来访者句」均指角色为来访者（`client` / `user` / `seeker`）的轮次；百分比在各自**阻抗子集**或**合作子集**内计算。

## 〇、统计口径（读表前必读）

| 概念 | 说明 |
|------|------|
| **对话数** | 数据集中独立会话/角色条数（AnnoMI 按 transcript id；MESC/ESConv 按 `character_id` 或数据集条目）。 |
| **来访者 utterances** | 全量对话里来访者轮次数；与「二分类已标注子集」条数不同。 |
| **二分类平表** | 一行 = 一条「来访者回应 + 上文」样本；MESC 的 `labeled/mesc_binary.json` 为平衡采样子集（**4,467** 条），不是全量句数。 |
| **对话视图** | `views/{annomi,esconv,mesc}.json`：按对话聚合，轮级带 `binary_label` / 细粒度标签；部分首轮或结构原因可为 `null`（见各集说明）。 |
| **阻抗细粒度（PsyFIRE）** | 以各集「阻抗」子集为分母；MESC **以 `views/mesc.json`（与 `labeled/mesc_resist.json` 平表一致）为准**；旧版 `labeled/mesc_resist_legacy.json`（1,608 条）为历史模型平表。 |
| **RECAP** | `recap/dialogues.json` 中大量来访者句**未打二分类**（`binary_label == null`），属「仅 target 句标注」设计；阻抗/合作平表仅覆盖有标签子集。 |
| **ExTES 二分类** | `extes/binary.json` 体积约 **129MB**，已写入 `.gitignore`，克隆仓库后需本地生成或单独拷贝。 |

**分布要点（与业务对齐）**

- **AnnoMI**：C1 占约一半，符合 MI 中大量短回应。  
- **ESConv**：A2 极高，众包「怼」类表述多。  
- **MESC**：A1 与真实治疗中「挑战」表述一致；D1/D2 占比仍低于 RECAP。  
- **RECAP**：B2、D1、D2 等类更均衡；**RECAP 的「忽视/岔开」在英文数据集中整体偏少**。  
- **ExTES**：A2+B5 主导，合成语料与 ESConv 类似存在 **A2 偏斜**，混合训练需考虑降采样或类别权重。

## 八、复现统计（维护用）

在仓库根目录执行（需 Python 3）：

```bash
python3 -c "
import json
from pathlib import Path
from collections import Counter
R = Path('workspace/results')
# 示例：Character View 来访者句与二分类
for fn in ['views/mesc.json','views/esconv.json','views/annomi.json']:
    data = json.loads((R/fn).read_text(encoding='utf-8'))
    c = sum(1 for d in data for t in d['dialogue'] if t.get('speaker') in ('client','user','seeker'))
    print(fn, 'dialogs', len(data), 'client_turns', c)
"
```

实际生产统计应以提交时的 `workspace/results/` 与 `workspace/dataset/` 快照为准；本文数字 **生成自 2026-04-18 工作区文件**。
